# Simple Interest Calculator

A Bash script that calculates simple interest from user input.

## Inputs
- Principal amount
- Rate of interest (% per year)
- Time period (years)

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## Usage
    chmod +x simple-interest.sh
    ./simple-interest.sh
